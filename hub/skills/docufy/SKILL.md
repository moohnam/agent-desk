# docufy

현재 내용을 동료에게 차근차근 설명하듯, 자연스러운 '합니다'체의 설명형 보고서로 작성해주세요.
독자는 해당 내용과 배경을 잘 모르는 동료라고 생각해주세요. 핵심을 먼저 말하고, 배경과 이유, 구체적인 내용이 자연스럽게 이어지도록 써주세요.
짧은 항목들만 나열하지 말고 완결된 문장과 연결된 문장으로 설명해주세요. 전문 용어는 처음 나올 때 본문에서 쉽게 풀어주세요. 표와 목록은 비교하거나 순서를 보여줄 때 사용해주세요.
기술적 정확성은 유지하고, 확인된 사실과 추정은 구분해주세요. 문서로 정리하면서 불필요한 형식이나 설명을 덧붙이지는 말아주세요.

## 절차

1. 문서 작성
2. 문서 검토: 서브 에이전트를 활용하여 적대적으로 문서를 검토하여 불필요한 메타데이터가 들어가진 않았는지, 설명이 자연스럽게 연결되지 않는 부분은 없는지, 전문 용어가 설명이 없는 경우는 없는지 등을 보고함
3. 문서 수정: 검토된 내용을 바탕으로 문서를 수정함
4. 문서 검토
5. 문서 수정
